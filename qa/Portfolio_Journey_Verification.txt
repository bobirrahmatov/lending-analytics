PORTFOLIO JOURNEY PILOT — 2026-10-26

Scope
Portfolio and the legacy Trends alias only. Other pages' interaction behavior is
unchanged. Generated bundles share the module but its hooks activate on Portfolio.
The earlier broad Portfolio cross-filter prototype is superseded.

User journey
1. Keep shared page filters distinct from facility-only filters.
2. Select a chart segment; only its card drills, with a local breadcrumb.
3. Expand or Open analysis retains the exact selected records, units and period.
4. Focused analysis provides relevant metrics, charts, insights and methodology.
5. Charts/Data switch representation; table filtering never changes chart metrics.
6. Source associations and Linked facilities are separate views of distinct grains.
7. A table relationship/facility link opens a scoped child analysis. Related monitoring
   explicitly broadens status/aging for same-date matched facilities. A full-relationship
   action explicitly broadens to all that relationship's facilities within page filters.
8. One contextual Back restores the parent mode, query, pagination and scroll.
   Back to Portfolio restores the original local chart. All <chart> clears it.
9. A leaf population uses entity facts and facility exposure instead of trivial charts.

Chart interaction contracts
- TFA/Outstanding/Unused KPIs: selected balance -> product -> region -> relationship
  -> facility. USD units retained; balances counted once per facility snapshot.
- Portfolio facilities/relationships: respective distinct counting unit -> region
  -> relationship -> facility. Relationship counts across groups can overlap.
- Expired facilities: maturity age -> region -> relationship -> facility.
- Expired CAs: distinct relationships -> region -> relationship -> facility.
- New Facilities Approved/New deals: selected product and chosen period -> region
  -> relationship -> facility. Facility count retained.
- Pending Closure: selected aging and field -> product -> relationship -> facility.
  A TFA cell remains money, a count remains a count. Original pipeline bands retained.
- Past/Coming Due Covenants: supplied 1-30/31-45/46-60/61-90/>90 band -> region
  -> relationship. Counts are source associations; exact facility links remain intact.
- CCM: region -> CCM status -> owner -> relationship, within selected source population.
- Monitoring priorities: selected category/status -> region -> owner -> relationship.
- Top Relationships/ROTCE: directly opens the selected relationship analysis.
  Exposure and supplied period-specific ROTCE are distinct measures.
- SBL spread: selected bucket -> relationship -> facility; Direct OS, facility count
  and weighted spread retain their respective source definitions.
- SFT summary: selected SFT/non-SFT rows, preserving clicked balance or facility count.
- Trend cells: selected product and actual observation date(s), including comparison
  dates for variance cells. Latest snapshot KPI, dated balances and product breakdown.
  No today's-facility substitution for aggregate historical observations.
All local paths leave unrelated overview populations unchanged.

Analytical safeguards
Facility attribution uses exact region + relationship ID + facility ID and same
reporting date. Missing keys, mixed source dates for a key, multiple portfolio matches,
CA conflicts and non-USD exposure are rejected for attributed amounts, with records
retained. Linked exposure is deduplicated; missing amounts remain unavailable.
No sums across historical dates; no sum/average of relationship ROTCE ratios.
A narrowed selection has no fabricated comparison. Existing overview comparisons remain.
Internal prepared pal_* helper fields are omitted from visible details; exports retain
all matching prepared record fields. No source records are dropped by pagination.
