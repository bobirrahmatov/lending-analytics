PACKAGING AND LIMITS
Application deployment ZIP excludes sample records; the full package and data kit
include excel/runtime/ separately. All archives and deployed attachments are below
10,000,000 bytes and ZIP CRC checks pass. SHA256SUMS records final archive hashes.
No live Confluence upload, native permissions, CSP, Windows Access execution or
production ETL has been verified here. Native attachment APIs use the viewer's
same-origin session with HTTP revalidation, with no persistent financial cache.
Fixed filenames are not atomic across uploads: a mixed bundle is rejected. Static
asset caching is also controlled by the host; reload after replacing the app assets.
The 75,000-row JSON processing benchmark does not measure XLSX parsing or establish
five-second live end-to-end performance. SheetJS decompression is synchronous;
conversion yields periodically and repeated page interactions reuse validated data.
GitHub-hosted Actions previously could not start because of the account billing /
spending-limit restriction. Local checks are the validation evidence for this release.
