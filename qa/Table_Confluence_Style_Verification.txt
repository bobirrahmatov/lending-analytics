TABLE PALETTE, SEARCH CONTROLS AND PAGINATION — LOCAL VERIFICATION
28 October 2026

Cause
- Shared --pale/--ink variables preferred Confluence DS tokens, so gray neutral
  fills and near-black text replaced the local table palette. Body cells also
  lacked important background protection against native table CSS.
- A positioned search-input wrapper could paint over its sibling magnifier.
  Several inline/expanded searches did not include a magnifier at all.
- Column search cells had no top padding, placing inputs against their top
  border. Column filter buttons were separated from their fields in the headings.

Changes
- Table boundaries resolve dashboard light/dark colors directly. Scoped cell
  styles protect header, stripe, hover, total, border and text treatments.
- Category labels retain 14px semibold hierarchy; amounts remain neutral.
  Space font inheritance and semantic status/change pills remain intact.
- The shared search helper owns an 18px SVG inside the input wrapper, reuses
  existing magnifiers and supplies missing ones. Input padding separates the
  magnifier, text and clear action. Teardown restores the original markup.
- source/dashboard/ui.js is the canonical UI helper; the build regenerates
  attachments/credit-ui.js. Shared dashboard CSS remains canonical in source.
- Column searches have 12px top/bottom cell padding and adjacent 32px filter
  buttons, aligned at their vertical centers. Host padding/margin resets are
  scoped out; sorting remains in the heading and filters retain their behavior.
- Every shared pager displays Previous, Page n of n, Next. The separate row
  range and 10/25/50 page-size selector remain; numbered buttons are removed.
