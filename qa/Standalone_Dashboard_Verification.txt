STANDALONE LENDING ANALYTICS — 27 OCTOBER 2026
Release: 1.2.0

Scope
- Landing + 11 dashboards remain; Trends is a Portfolio compatibility route.
- Each Confluence fragment loads one credit-style.css, credit-ui.js,
  credit-loading-overlay.js and its matching page pair. No WCSpedia navbar,
  application login, entitlement, approval or access-request page dependency.
- Native Confluence permissions and authenticated same-origin attachment reads
  remain authoritative. No space/page permission change was performed.
- Dashboard-only controls/styles replace bundled portal sources. Native sidebar
  decoration touches only the configured dashboard IDs and preserves handlers,
  URLs, titles, dimensions and unrelated space links.
- Microsoft Access/VBA modules, staging workbooks and their generators removed.
  All six runtime XLSX inputs are unchanged; data grains, typed keys, dated join
  validation and existing financial calculations remain unchanged.
- Optional space file-drop guard is independent, uses no portal notifications,
  performs no upload, and is not a dashboard startup dependency.

npm run package: PASS — three CRC-checked archives below 10,000,000 bytes;

The suite includes all dashboard/expanded chart flows, real Highcharts/control
lifecycle, filters, Reset/tab races, inline chart/table drills, export populations,
search/sort/pagination, exact linkage, native sidebar scope, XLSX/JSON validation,
attachment permission/timeout failures, immutable partitions and startup cleanup.

New test_standalone_macros.cjs executes actual generated native macro scripts in
order on a bare host without portal globals: landing's eleven native links, no
financial landing fetch, dashboard dependency order, one startup overlay, all
six actual workbook loads, table row drill/Back, search/Reset and no refetch.
Native unrelated content and controls remain unchanged. Geometry is deliberately
covered by browser and existing real-chart tests, not claimed from this fixture.

Deployment limits
These are local checks and simulated native-host fixtures. Live Confluence
installation, host caching, network transfer and page/attachment permissions
were not exercised. This work does not establish a five-second live Excel load
or a zero-bug guarantee. Historical QA notes describe their own builds; use
Lending_Analytics_Deployment.txt for current installation instructions.
