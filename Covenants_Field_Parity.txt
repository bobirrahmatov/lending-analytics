COVENANTS — LEGACY FEATURE AND FIELD PARITY

Sources reviewed: covenantsHTMLPage.js, covenants.js, covenants-style.css,
covenants-page-style.css, covenants-local.html, Covenants_current.xlsx and
Covenants_Activity_Report.xlsx. Original source files are unchanged.

MAIN PAGE
- Covenant records = source PAST_DUE plus COMING_DUE association rows; covenant numbers may repeat.
- TFA and OSUC = distinct matched same-date USD portfolio facility balances, with prior weekday comparisons.
- Default Covenant–facility links includes IDs, relationship name, banker name, TFA and OSUC; Facility level
  groups the associations and lists their covenant numbers. Missing exposure or banker fields remain unavailable.
- Action Needed = all source PAST_DUE rows; share uses active covenant total.
- Coming Due = all explicitly COMING_DUE rows, with no upper-day cutoff.
- Distinct Relationships = non-empty relationship IDs in the filtered source.
- Past/Coming Due donut and by-region aging summary.
- Deferred/Waived/Deleted events and three-month regional comparison.
- Aging Severity by Region and all-source Product Program distribution.
- Relationship/underwriter grouping, covenant records, all source records and
  activity records in one detail area. Page size 10, numbered pages, search,
  per-column search/filter/sort. Summary tables have no data-table controls.

EXPANSIONS
- Past due / regional / severity: four KPIs, regional aging, aging mix,
  product program, top-five underwriters, concentration and unknown-age insight.
- Coming due: same plus frequency, upcoming timeline and next-due records tab.
- Action Needed: same plus frequency, region totals and most-overdue records tab.
- Total: status mix, status by region, products and top-five underwriters.
- Relationships: action and volume rankings, products, underwriters and top ten.
- Product: product mix, region totals, frequency, underwriters and product detail.
- Activity: maker-month trend and region donut; event KPIs and supporting records.
Every expansion has one bottom tabbed detail area and original-field CSV export.
Charts, tables, KPI values and insights each have calculation methodology.

INTENTIONAL CHANGES
The old coarse 1–45 / 46–90 / >90 bands are replaced with portfolio bands
1–30 / 31–45 / 46–60 / 61–90 / >90 for BOTH statuses. Exact file categories
win; otherwise supplied days or effective due date minus as-of date are used.
Coarse categories without an exact day remain unclassified. Unknown aging is
not silently discarded. Due today belongs to the first band. A deferred date
alone is not evidence of approval. No future/historical data is estimated.
NAM and LATAM combine as Americas ONLY in activity views, as in the original.
Inactive/deactivated activity joins Deleted. All event types remain in records.
The new look uses WCSpedia components instead of the old compiled utility CSS.

DATA COVERAGE AND PUBLICATION
All original raw properties survive normalization and source CSV export. Screen
columns avoid duplicate aliases and entirely empty fields. Record dialogs retain
raw fields. All source records includes statuses not used in the headline total.
Production consumes the existing validated monitoring/activity JSON contract;
optional columns below must be retained in the prepared JSON for complete detail.
The browser cannot recreate fields omitted by an upstream export. No live data
was replaced. The local and workbook samples stay separate to avoid mixed dates.
For repeatable local preview capture: node tools/capture_covenants_fixture.cjs.
After capture: python3 tools/build_pages.py. Production bundles exclude fixtures.
