Build, preview and deploy

Serve the extracted project over local HTTP, then open /pages/lendinganalytics.html (this file is the separate installation guide). For example, from the project folder:

python3 -m http.server 8770 --bind 127.0.0.1

The build uses this repository’s dashboard components. It requires no knowledge-management application, staging database or backend:

python3 tools/build_pages.py
python3 tools/verify_page_package.py
python3 tools/build_integration_kit.py
python3 tools/package_release.py

For Confluence, the native page IDs and attachment host 3845862527 are already configured in the wcs space. Keep the native Confluence sidebar and page tree. Each supplied page fragment loads the same credit-style.css, UI controls and loading helper, followed by its matching settings → logic → HTMLPage sequence. No shared knowledge-management navbar or access page is required. The fragments are intended for approved HTML macros, not standalone browser pages.

For the requested sample walkthrough, upload the contents of excel/runtime/ to attachment page 3845862527; the provided macros use allowSampleData:true. For live use, set it to false and publish approved files marked is_demo:false. Upload all matching workbooks first and credit-manifest.json last. Every workbook Metadata sheet must match the manifest bundle ID; mixed releases are rejected. Never replace existing live datasets with starter samples. See the output schema, the upstream mapping schema and the integration guide before preparing live data.

Interaction model

Page filters affect supported page populations. Chart clicks drill within one full-row widget, preserving the selected metric and using visible breadcrumbs. Other charts retain their scope. Table rows use the same local journey, with a return action that restores table state.

Expand opens a modal analysis above the page navigation, with relevant KPIs, paired analytical charts and the supporting table below. Close returns to the originating dashboard. The compact “In this selection” summary has no methodology button or date.

Related datasets retain their own grain and reporting date. Exact entity identifiers and compatible CA keys link records; unmatched or ambiguous amounts remain unavailable. Monetary cells use theme-aware text, category labels are emphasized, and downloads include all matching rows across table pages.
