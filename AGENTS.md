# Lending Analytics project rules

- Read `Lending_Analytics_Deployment.txt` before changing deployment, navigation, data loading or interactions. It supersedes historical feature notes in `INSTALL.txt`.
- This department uses an existing WCSpedia Confluence space. Do not require a new backend, privileged service account, server access, plugin installation or custom REST endpoint.
- Keep `{include:wcs:navBar}`, the single global `wcspedia-style.css` stylesheet and native title/sidebar. The confirmed space key is `wcs`; landing page is `3782729579` and attachment host is `3845862527`. Enhance native sidebar controls without replacing their handlers, widths or page tree. Production macros are content fragments using settings, logic and matching HTMLPage renderer.
- Maintain Lending Analytics as the parent of 11 dashboards. `overview.html` is Underwriters Summary; `portfolio.html` is Portfolio. `trends.html` is a compatibility route. Do not recreate the removed Sources page; retain source-control datasets.
- Edit shared application modules in `attachments/credit-*.js` and shared styling in `source/wcspedia/credit-dashboard.css`. Rebuild generated `*Page.js`, `*HTMLPage.js`, preview pages and Confluence fragments with `npm run build`. Do not manually patch generated bundles.
- Page filters and local drills have separate scope. Drills fill one widget row and retain the metric and breadcrumb. Expanded analyses use the shared modal, supporting records and state restoration. Preserve search, column controls, sorting, the 10-row default and all-matching export behavior.
- Keep events, obligations/associations, facilities and historical snapshots at their own grains. Join only exact identifiers with compatible reporting dates and CA context. Do not infer joins from names or owners. Deduplicate facility exposure at the valid snapshot grain. Preserve unmatched records and unavailable values; do not invent comparisons or sum ROTCE ratios.
- The default runtime uses six stable-name Excel files from `excel/runtime/`, each with `Data` and `Metadata` sheets, plus `credit-manifest.json`. Preserve typed fields, schema/version metadata, bundle identity and count validation. Default asset/data URLs have no version query or hash suffix. Keep the existing immutable JSON/Access path as an optional large-data workflow.
- Keep sample data separate from live records. Production rejects sample manifests unless `allowSampleData:true` is explicitly set. Supplied native macros enable that setting for the requested samples; approved live deployment must disable it and use validated `is_demo:false` files. Runtime banner removal does not remove file provenance. Never overwrite live attachments with samples.
- With fixed Excel filenames, upload every validated workbook/optional file first and its manifest last. Updates are not atomic: reject mixed bundle identities rather than combining data. Retain only already-loaded validated snapshots until reload; do not persist financial data in browser storage. Every attachment and upload ZIP must remain below 10,000,000 bytes. Sample uploads stay separate from the application deployment ZIP.
- The user-facing landing is `pages/lendinganalytics.html`; `Start_Here.html` is an operator guide. Keep the existing sidebar and an editorial introduction with three Citi Insights-style subject cards, rounded attachment images and separate links to all 11 dashboards. Do not make multi-destination cards a single clickable control. Keep space font inheritance, scoped important typography/scrollbar protection and semantic colours; do not reset native page/sidebar geometry.
- Run `npm test` for substantive shared logic changes and `npm run package` for releases. Historical generators in `tools/README.txt` are not routine build steps. Review layout in a real browser for visual changes.
- Preserve `LICENSES.txt` and bundled upstream notices. No broader redistribution rights are asserted for internal assets.
- Local fixtures do not establish live Confluence access, Windows Access compatibility or live network performance. Report those limits accurately.
